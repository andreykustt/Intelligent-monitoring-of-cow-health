# Стадо — интерфейс MVP

Локальное приложение React. Свой дизайн реализован в CSS без внешних шрифтов, изображений и UI framework.

## Макеты и переходы
- Вход: две колонки; слева название и учебный контекст, справа форма и сообщения об ошибках.
- Рабочее пространство: тёмно-зелёная боковая панель 242px, верхняя строка 86px, светлая область содержимого.
- Обзор: четыре карточки сводки, распределение анализа, график истории, переход к ручному вводу.
- Монитор: поиск/фильтр/сортировка → постраничная таблица → карточка животного.
- Карточка: результат анализа → девять показателей → график → журнал наблюдений → создание/исправление/история.
- Уведомления: фильтр → список → подробности и история действий → подтверждение/закрытие.
- Администратор: симуляции, животные, пользователи. Сервер проверяет права независимо от навигации.

## Визуальные правила
Фон #f4f7f5, текст #20372d, акцент #24684f, sidebar #173e31. Карточки белые, радиус 12px. Основной текст 16px; вспомогательные подписи меньше. Аномалия янтарная, отсутствие аномалии зелёное, недостаток данных серый. Статусы всегда имеют текст. «Нет показаний» и «Устарело» относятся к отдельной метрике, результат модели — к окну анализа.

## Состояния
Загрузка не подменяется нулём; пустая выдача имеет объяснение. Ошибки API показаны рядом с формой/данными. При разрыве WS сохраняются последние значения и появляется индикатор переподключения. На повторном подключении и refocus запрашивается REST snapshot. На экране постоянно обозначены учебный характер и отсутствие диагностического заключения.

## Адаптация
До 800px навигация сворачивается, карточки в две колонки, формы в одну, плотные таблицы прокручиваются горизонтально. Все поля имеют label, ошибки role=alert, кнопки клавиатурный focus.
