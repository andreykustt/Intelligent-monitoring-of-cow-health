# Reusable prompt for coding agents

Task: <one concrete change from docs/implementation-plan.md>.
Scope: <exact directories/files>. Do not touch unrelated modules.
Read: root AGENTS.md, applicable local AGENTS.md, and only relevant contracts.
Acceptance: <observable behavior + tests>.
Constraints: do not silently change API/event/DB contracts; no extra infrastructure; don't assert tests ran unless actually run.
Output: change summary, paths, commands/tests/results, limitations, suggested next bounded task. Update docs/progress.md.
